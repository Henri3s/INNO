中国国际大学生创新大赛

评委高频问题 · 含考察要点 · 分赛道展示
通用问题 · 适用于所有赛道 · 50问
1项目背景与痛点
评委想确认：你们发现的问题是不是真问题？值不值得解决？
Q1
请用一句话概括你们解决的核心痛点是什么？
🎯 考察点：团队是否对痛点有清晰、精准的定义，能否在最短时间内让评委理解项目的价值主张。
Q2
这个痛点有多痛？目标用户愿意为此付费吗？
🎯 考察点：痛点的真实性和迫切程度。评委希望看到用户调研数据、付费意愿验证，而非主观臆断。
Q3
你们是怎么发现这个痛点的？做了哪些调研？
🎯 考察点：问题发现过程的科学性和严谨性。问卷数量、访谈深度、实地调研等一手数据比二手资料更有说服力。
Q4
这个市场有多大？你们的目标市场规模（TAM/SAM/SOM）是多少？
🎯 考察点：团队对市场空间的理性判断。需要给出有依据的测算逻辑，而非夸大数字。
Q5
为什么是现在做这个项目？时机成熟了吗？
🎯 考察点：对行业趋势和技术成熟度的判断。政策红利、技术拐点、社会需求变化等外部驱动因素是否被充分认知。
2创新性与技术
评委想确认：你们的创新是真创新还是伪创新？技术壁垒有多高？
Q6
你们的项目核心创新点是什么？是技术创新还是模式创新？
🎯 考察点：创新类型的清晰界定。技术创新看专利和论文支撑，模式创新看商业逻辑的独特性。
Q7
你们的核心技术是什么？跟现有技术相比有什么本质区别？
🎯 考察点：技术原理的掌握深度。团队成员能否用通俗语言讲清楚技术内核，而非堆砌术语。
Q8
你们有哪些知识产权？专利是授权还是受理？所有权归属清晰吗？
🎯 考察点：知识产权的真实性和归属。受理中的专利不等于授权专利；是否有职务发明纠纷风险。
Q9
你们的技术壁垒是什么？别人多久能复制？
🎯 考察点：护城河的深度。专利组合、技术秘密、数据积累、网络效应、品牌壁垒等。
Q10
相比市面上已有的解决方案，你们的差异化在哪里？
🎯 考察点：竞品分析的深度。评委希望看到具体的对比维度（性能、价格、体验、场景），而非笼统的「我们更好」。
Q11
你们的项目如何体现「互联网+」或数字化/智能化的特征？
🎯 考察点：技术与产业的融合深度。是否真正用技术解决了传统行业的痛点。
Q12
如果技术路线走不通，你们的备选方案是什么？
🎯 考察点：风险意识和技术储备。评委欣赏有Plan B的团队。
3产品与解决方案
评委想确认：产品是不是真的做出来了？用户反馈如何？
Q13
你们的产品/服务目前做到什么阶段了？有MVP吗？
🎯 考察点：项目落地进度。创意组可以接受概念验证，创业组必须有实际运营数据。
Q14
产品的核心功能是什么？用户最常用的是哪个功能？
🎯 考察点：产品定位的聚焦程度。评委希望看到「少而精」的核心功能，而非功能堆砌。
Q15
你们的产品有实际用户吗？复购率和留存率是多少？
🎯 考察点：产品市场契合度（PMF）的验证。真实用户数据比任何商业计划书都有说服力。
Q16
产品的应用场景有哪些？哪个场景是你们的主战场？
🎯 考察点：场景聚焦能力。评委不希望看到「所有场景都能用」的万能产品。
Q17
你们的产品迭代频率是怎样的？根据什么来迭代？
🎯 考察点：产品运营能力和用户导向思维。是否有数据驱动的迭代机制。
Q18
产品的成本结构是怎样的？单位经济模型算过吗？
🎯 考察点：对产品商业可行性的理解。评委希望看到团队算过账。
Q19
如果用户量增长10倍，你们的产品架构能支撑吗？
🎯 考察点：技术架构的可扩展性和团队的前瞻性思考。
4商业模式与盈利
评委想确认：这事能不能赚钱？怎么赚钱？能持续赚钱吗？
Q20
你们的商业模式是什么？收入从哪里来？
🎯 考察点：商业模式的清晰度和可行性。完整的收入模型——谁付费、付多少、为什么付。
Q21
你们目前有收入吗？收入结构是怎样的？
🎯 考察点：商业化验证的真实性。一次性收入还是经常性收入？大客户依赖度如何？
Q22
项目何时能盈利？盈亏平衡点在哪里？
🎯 考察点：财务规划的合理性。评委希望看到有依据的财务预测。
Q23
你们的定价策略是什么？为什么定这个价格？
🎯 考察点：定价逻辑的合理性。成本加成、价值定价、竞争定价、渗透定价的依据。
Q24
你们的营销和推广策略是什么？获客成本（CAC）是多少？
🎯 考察点：市场推广的可执行性。获客效率和渠道可行性。
Q25
如果大公司进入这个领域，你们怎么应对？
🎯 考察点：竞争壁垒和战略思维。是否有差异化生存策略。
Q26
你们需要融资吗？融资用途、出让股份、估值依据是什么？
🎯 考察点：融资规划的合理性。钱花在哪里、估值是否有依据、股权结构是否合理。
5市场与竞争
评委想确认：你们了解市场吗？知道对手是谁吗？凭什么赢？
Q27
你们的直接竞品和间接竞品分别是谁？做过详细的竞品分析吗？
🎯 考察点：竞品分析的全面性。「没有竞品」通常意味着没有市场。
Q28
你们的竞争优势是什么？这个优势能持续多久？
🎯 考察点：可持续竞争优势。先发优势不等于持续优势。
Q29
你们的目标用户画像是什么样的？第一批种子用户从哪里来？
🎯 考察点：用户洞察的精准度和获取种子用户的可行路径。
Q30
你们的渠道策略是什么？如何触达目标用户？
🎯 考察点：渠道可行性和成本效益。
Q31
你们覆盖了多少客户？转化率是多少？
🎯 考察点：市场验证的真实数据。完整的漏斗数据。
Q32
国际市场有考虑吗？出海计划是怎样的？
🎯 考察点：格局和视野。对海外市场的认知和初步规划。
6团队维度
评委想确认：为什么是你们这个团队能做成？
Q33
介绍一下你们的团队结构和分工。为什么这个组合能做成这件事？
🎯 考察点：团队配置与项目需求的匹配度。技术、商业、运营等关键角色是否齐备。
Q34
团队成员的背景和专业是什么？跟这个项目的关联度如何？
🎯 考察点：专业能力与项目的匹配度。是否「学以致用」。
Q35
请举例说明某个团队成员在项目中的具体贡献。
🎯 考察点：团队真实参与度的验证。「全员参与」还是「一人干活、全员挂名」。
Q36
你们的股权结构和决策机制是怎样的？
🎯 考察点：团队治理的规范性。股权分配、决策机制、退出机制。
Q37
你们有哪些外部资源支持（导师、企业、政府、投资机构等）？
🎯 考察点：资源整合能力。能否撬动外部资源为己所用。
7运营与成果
评委想确认：项目是不是真的在运转？取得了什么实际成果？
Q38
项目目前取得了哪些阶段性成果？用数据说话。
🎯 考察点：成果的真实性和可量化程度。
Q39
你们跟哪些企业或机构有合作？合作到什么程度？有合作协议吗？
🎯 考察点：合作关系的真实性和深度。意向协议和正式合同的含金量不同。
Q40
项目带动了多少就业？直接就业和间接就业分别怎么算的？
🎯 考察点：社会贡献的测算依据是否合理。
Q41
项目是否有媒体报道或社会认可？获得过哪些奖项？
🎯 考察点：社会影响力的佐证。第三方认可更有说服力。
Q42
项目的可持续性体现在哪里？核心成员毕业后项目还能继续吗？
🎯 考察点：项目的长期生命力。是否有传承机制和稳定运营模式。
8教育维度（成长与收获）
评委想确认：参赛过程对学生的成长真的有价值吗？
Q43
在做项目的过程中，你应用了哪些在学校学到的知识和技能？
🎯 考察点：学以致用的能力。这是教育维度的重要评分点。
Q44
你是如何想到要做这个项目的？灵感来源是什么？
🎯 考察点：创新意识的来源。越贴近真实需求越好。
Q45
做这个项目，你最大的收获和成长是什么？
🎯 考察点：参赛的教育价值。真实的成长故事。
Q46
你们学校对创新创业教育有什么支持政策？指导老师给了哪些帮助？
🎯 考察点：高校双创教育的实效性。
9公益与社会价值
评委想确认：项目对社会有什么真实贡献？受益者是谁？
Q47
你们的项目服务了多少人？受益群体是谁？有没有数据证明？
🎯 考察点：社会影响力的可量化程度。是否有前后对比数据。
Q48
项目的公益性或社会价值具体体现在哪里？跟商业项目有什么区别？
🎯 考察点：公益属性的真实性和可持续性。
Q49
如果政府停止补贴或外部资助中断，项目如何持续运营？
🎯 考察点：公益项目的可持续性设计。是否有「造血机制」。
Q50
你们的模式是否可以复制到其他地方？有没有示范效应？
🎯 考察点：可复制性和推广价值。
高教主赛道专属 · 16问
1学术与科研转化
高教主赛道侧重前沿技术、科研成果转化和学术深度
G1
这个项目跟你的科研课题是什么关系？是导师课题衍生还是学生自主发起？
🎯 考察点：项目的原创性归属。评委需要区分「学生自主项目」和「导师项目学生参与」。
G2
你们的成果发表了哪些论文？在什么级别的期刊/会议？
🎯 考察点：学术影响力。论文质量比数量重要，一作/通讯作者含金量更高。
G3
从实验室到产品，中间跨越了哪些关键障碍？
🎯 考察点：科研成果转化的实际难度认知。评委想看团队是否理解「能做出来」和「能卖出去」之间的鸿沟。
G4
你们的技术指标跟国际领先水平对比如何？
🎯 考察点：技术水平定位。需要有对标数据，而非自说自话。
G5
项目是否涉及核心技术卡脖子问题？对国家战略有什么意义？
🎯 考察点：战略价值和格局。高教主赛道鼓励面向国家重大需求的项目。
G6
实验室环境和实际使用环境的差异，你们怎么处理？
🎯 考察点：工程化能力。从Lab到Product的关键路径是否清晰。
2产业化与商业验证
高教主赛道创业组尤其关注产业化进度
G7
你们做了哪些概念验证（POC）？结果如何？
🎯 考察点：技术验证的真实性和完整性。
G8
有没有跟产业方做过联合测试或小批量试产？
🎯 考察点：产业对接的深度。意向≠实际测试。
G9
产品的良率、稳定性、一致性如何保证？
🎯 考察点：量产能力的认知。实验室做一台≠工厂做一万台。
G10
你们对标的是哪个细分市场？为什么不选更大的市场？
🎯 考察点：市场选择的战略思考。评委更认可「精准切入」而非「大而全」。
G11
从技术到产品的资金需求是多少？有详细预算吗？
🎯 考察点：资金规划能力。预算要具体到研发、测试、认证、生产等各环节。

评委对两组的期待不同
G12
（创意组）你们还没成立公司，如何跟客户签协议？项目落地的可行性在哪？
🎯 考察点：创意组的落地路径是否可信。
G13
（创业组）公司注册多久了？目前营收和利润情况？
🎯 考察点：创业组的实际经营状态。空壳公司和真实运营的差距。
G14
（创业组）团队成员全职还是兼职？为什么相信自己能赢过大公司？
🎯 考察点：创业决心和竞争力。
G15
你们的三年规划是什么？每年的关键里程碑是什么？
🎯 考察点：战略规划的清晰度和可执行性。

你们去了哪些乡村？待了多长时间？做了什么？

H9
项目前后当地最大的变化是什么？有对比数据吗？
🎯 考察点：实效性的直观证明。

H14
项目形成的经验模式能否总结成可推广的标准方案？

如果项目团队成员毕业离开，当地的运营谁来接手？

实训基地和实习经历对项目有什么帮助？
🎯 考察点：实践教学的价值体现。
Z5
你们的技能水平跟行业一线标准对比如何？
🎯 考察点：专业技能的行业认可度。

项目是否形成了可推广的技术方案或工艺改进？
🎯 考察点：成果的标准化程度。

企业方对你们的技术服务满意度如何？有没有持续合作？
